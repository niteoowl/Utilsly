클릭 또는 드래그 • Ctrl+V 붙여넣기

사용 가이드
expand_more
이미지 전체에 블러(Blur, 흐림) 효과를 적용하여 몽환적인 분위기를 연출하거나, 배경으로 쓰기 좋게 만드세요. 개인정보 보호를 위해 이미지를 전체적으로 흐리게 만들 때도 유용합니다.

슬라이더를 조절하여 블러의 강도(픽셀 반경)를 실시간으로 확인하며 미세하게 조정할 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 블러 효과를 줄 이미지를 드래그하거나 클릭하여 업로드합니다.
  2. '블러 강도' 슬라이더를 움직여 원하는 만큼 흐리게 만듭니다.
  3. 미리보기를 확인한 후 '이미지 저장' 버튼을 클릭합니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
특정 부분만 블러 처리할 수 있나요?
현재 버전은 이미지 전체에 블러 효과를 적용합니다. 부분 블러 기능은 추후 업데이트될 예정입니다.
원본 이미지가 변경되나요?
아니요, 원본 파일은 그대로 유지되며 블러 처리가 적용된 새로운 이미지를 별도로 다운로드하게 됩니다.

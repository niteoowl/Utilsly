더미 이미지 생성

필요한 크기와 색상의 플레이스홀더 이미지를 즉시 생성하고 URL을 복사하거나 저장하세요.

사용 가이드
expand_more
웹 개발이나 디자인 프로토타입을 만들 때 실제 이미지가 준비되지 않은 경우, 플레이스홀더 이미지를 빠르게 생성하여 사용할 수 있습니다. 원하는 해상도와 배색을 자유롭게 선택하세요.
광고 영역 (상단)
check_circle 사용 방법
  1. 이미지의 너비와 높이를 픽셀(px) 단위로 입력합니다.
  2. 배경색과 텍스트 색상을 선택하거나 헥사 코드를 직접 입력합니다.
  3. 이미지 중앙에 표시될 문구(옵션)를 작성합니다. 입력하지 않으면 크기가 표시됩니다.
  4. 설정이 완료되면 생성된 이미지를 다운로드하거나 URL을 복사하여 코드에서 활용하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
URL을 그대로 프로젝트에 써도 되나요?
본 서비스에서 제공하는 URL은 외부 참조용 플레이스홀더 서비스(via.placeholder.com 등)를 기반으로 생성되므로, 네트워크가 연결된 환경에서 테스트용으로 자유롭게 사용 가능합니다.

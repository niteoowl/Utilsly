SVG PNG 변환

벡터 SVG 파일을 PNG 이미지로 변환하세요. 스케일(해상도)을 조절할 수 있습니다.

cloud_upload

SVG 파일을 드래그하거나 클릭하여 업로드

SVG 파일 지원 • Ctrl+V 붙여넣기

지정된 배율로 이미지를 확대/축소하여 저장합니다.

사용 가이드
expand_more
확대해도 깨지지 않는 SVG 벡터 파일을 투명도가 유지되는 고화질 PNG 형식으로 변환하세요. 로고, 아이콘, 그래픽 디자인 소스를 웹사이트나 문서 애플리케이션 등 PNG 형식이 필요한 곳에 즉시 사용할 수 있도록 최적화해줍니다.

단순한 변환을 넘어 해상도 배율(Scale) 조절 기능을 제공하므로, 원본 벡터 이미지의 선명함을 유지하면서도 원하는 만큼 확대된 고해상도 이미지를 얻을 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 변환할 SVG 파일들을 업로드 영역에 드래그하거나 클릭하여 업로드합니다.
  2. '해상도 배율(스케일)' 값을 설정합니다. 크게 입력할수록 더 큰 사이즈의 고해상도 이미지가 생성됩니다.
  3. 미리보기 리스트를 확인하고 '전체 다운로드' 버튼을 클릭합니다.
  4. 변환된 모든 PNG 파일이 하나의 ZIP 압축 파일로 묶여 기기에 저장됩니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
해상도 배율(스케일)이 무엇인가요?
원본 SVG 크기를 기준으로 몇 배로 확대하여 저장할지 결정합니다. SVG는 벡터 이미지이므로 10배 이상 크게 확대해도 깨짐 없이 선명한 PNG를 얻을 수 있습니다.
여러 파일을 한 번에 변환할 수 있나요?
네, 여러 SVG 파일을 동시에 드래그 앤 드롭하여 일괄적으로 PNG로 변환하고 ZIP으로 다운로드할 수 있어 작업 시간을 절약해줍니다.

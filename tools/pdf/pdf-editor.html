사용 가이드
expand_more
PDF 편집기를 사용하면 PDF 파일에 텍스트, 이미지, 서명을 추가하고 페이지를 회전시킬 수 있습니다. 모든 작업은 브라우저에서 처리되며 서버에 파일이 업로드되지 않습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 편집할 PDF 파일을 업로드합니다.
  2. 상단 도구 모음에서 원하는 편집 도구(텍스트, 이미지, 서명 등)를 선택합니다.
  3. PDF 미리보기 위에서 클릭하여 요소를 추가합니다.
  4. 여러 페이지인 경우 페이지 네비게이션으로 이동합니다.
  5. '편집된 PDF 다운로드' 버튼으로 최종 파일을 저장합니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
추가한 요소를 삭제할 수 있나요?
'실행취소' 버튼을 클릭하면 마지막으로 추가한 요소를 제거할 수 있습니다.
암호화된 PDF도 편집할 수 있나요?
암호가 걸린 PDF는 편집할 수 없습니다. 먼저 'PDF 암호 제거' 도구를 사용하세요.
파일이 서버에 저장되나요?
아니요, 모든 처리는 브라우저에서 로컬로 수행됩니다. 파일은 서버에 전송되지 않습니다.

사용 가이드
expand_more
메타데이터 수정기는 사진 파일 내부에 저장된 디지털 정보(EXIF)를 사용자가 직접 확인하고 원하는 내용으로 변경할 수 있는 도구입니다. 개인정보 보호를 위해 촬영 일시를 바꾸거나, 저작권 정보를 입력하는 등 다양한 용도로 활용할 수 있습니다.

모든 수정 과정은 브라우저 내에서 로컬 처리되므로, 원본 이미지가 서버로 전송되지 않아 보안상 매우 안전합니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 파일 업로드: 수정하고 싶은 JPG/JPEG 파일을 선택하거나 드래그하여 올립니다.
  2. 정보 확인: 분석이 완료되면 우측 편집창에 현재 저장된 메타데이터 정보가 표시됩니다.
  3. 데이터 수정: 날짜, 제조사, 저작자 등 변경하고 싶은 필드에 새로운 값을 입력하세요.
  4. 다운로드: '수정된 이미지 다운로드' 버튼을 누르면 새로운 메타데이터가 적용된 파일이 저장됩니다.

help 자주 묻는 질문 (FAQ)
PNG나 GIF 파일도 수정 가능한가요?
본 도구는 EXIF 표준을 따르는 JPG/JPEG 포맷에 특화되어 있습니다. PNG 파일의 경우 별도의 메타데이터 구조를 사용하므로 현재는 지원하지 않습니다.
입력한 날짜 형식이 중요합니까?
네, EXIF 표준 규격인 'YYYY:MM:DD HH:MM:SS' 형식을 준수해야 다른 갤러리 앱에서도 정상적으로 인식됩니다.
모든 데이터를 지우고 싶으면 어떻게 하나요?
비어있는 필드로 저장하면 해당 정보가 삭제되거나 빈 값으로 대체됩니다. 전체 일괄 삭제를 원하시면 사촌 도구인 '메타데이터 지우기'를 추천드립니다.

사용 가이드
expand_more
메타데이터 수정기는 디지털 사진 파일 안에 숨겨진 정보(Exif 데이터)를 쉽고 투명하게 보여주는 도구입니다.

사진이 찍힌 날짜, 카메라 기종, 렌즈 설정은 물론 위치 정보(GPS)까지 상세하게 확인할 수 있습니다. 개인정보 보호를 위해 이를 지우거나 수정하기 전 상세 내용을 검토할 때 필수적인 도구입니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 중앙의 업로드 영역을 클릭하거나 이미지를 끌어다 놓습니다.
  2. 사진이 로드되면 우측 패널에 해당 사진의 메타데이터(Exif)가 목록으로 나타납니다.
  3. 촬영 날짜, 기기 정보 등을 클릭하여 수정(준비 중) 또는 확인합니다.
  4. 수정 완료 후 '저장' 버튼을 눌러 결과물을 다운로드합니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
어떤 파일 형식을 지원하나요?
메타데이터(Exif)를 주로 사용하는 JPG, JPEG 및 일부 TIFF 파일을 지원합니다. PNG나 GIF는 Exif 표준을 사용하지 않아 정보가 적을 수 있습니다.
업로드한 이미지가 서버에 저장되나요?
아니요, Utilsly의 모든 도구와 마찬가지로 이미지는 사용자 브라우저 내에서만 처리되며 외부로 전송되지 않아 매우 안전합니다.

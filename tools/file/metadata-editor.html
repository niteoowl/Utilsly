메타데이터 수정기

사진 파일속에 숨겨진 기기 정보, 위치 정보, 촬영 날짜 등을 확인하고 관리하세요.

upload_file

이미지를 드래그하거나 클릭하여 업로드

정보 확인

* 현재 버전은 상세 메타데이터 뷰어 기능을 우선 제공하며, 저장 및 수정 기능은 준비 중입니다.

사용 가이드
expand_more
디지털 카메라나 스마트폰으로 촬영한 이미지에는 촬영 장비, 설정, 위치 정보 등 방대한 메타데이터(EXIF)가 기록되어 있습니다.

이 도구를 사용하면 눈에 보이지 않는 이미지속 정보를 투명하게 확인하고 관리할 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 메타데이터를 확인하고 싶은 이미지 파일을 업로드 영역에 끌어다 놓습니다.
  2. 이미지가 로드되면 자동으로 EXIF 데이터를 분석하여 우측과 하단에 표시합니다.
  3. 기기 모델명(Make/Model), 노출(ISO/F-Stop), 촬영 날짜, GPS 위치(있는 경우) 등을 확인하세요.
  4. 다른 이미지를 확인하려면 '다른 이미지' 버튼을 눌러 초기화합니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
개인 정보 유출 위험은 없나요?
모든 처리는 사용자의 웹 브라우저 내에서 직접 이루어집니다. 이미지가 서버로 전송되지 않으므로 개인 위치 정보 등이 외부에 유출되지 않습니다.
모든 이미지 파일에서 작동하나요?
주로 JPEG 파일에서 EXIF 데이터를 완벽하게 지원하며, PNG나 WEBP는 촬영 기기 설정에 따라 정보가 없을 수도 있습니다.

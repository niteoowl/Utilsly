YAML ↔ JSON 변환기

YAML과 JSON 데이터 형식을 서로 변환합니다. 설정 파일을 다룰 때 유용하게 사용할 수 있습니다.

사용 방법
expand_more
  1. 입력: 변환하고 싶은 YAML 텍스트를 왼쪽 'YAML Template' 창에 입력하세요.
  2. 확인: 입력과 동시에 오른쪽 'JSON Output' 창에 변환된 JSON 결과가 나타납니다.
  3. 활용: 변환된 JSON 데이터를 복사하여 API 페이로드나 설정 파일로 사용하세요.

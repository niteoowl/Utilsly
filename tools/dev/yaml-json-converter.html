YAML ↔ JSON 변환기

YAML과 JSON 데이터 형식을 서로 변환합니다. 설정 파일을 다룰 때 유용하게 사용할 수 있습니다.

이용 가이드 및 FAQ
expand_more
YAML과 JSON 중 무엇이 더 좋은가요?
YAML은 사람이 읽고 쓰기 편해 설정 파일에 주로 쓰이고, JSON은 기계 간 데이터 전송(API)에 주로 쓰입니다. 용도에 맞게 변환해 사용하세요.
변환 시 주석도 유지되나요?
JSON은 주석을 지원하지 않으므로, YAML을 JSON으로 변환하면 주석 내용은 사라집니다.

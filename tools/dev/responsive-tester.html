반응형 디자인 테스터

URL을 입력하고 다양한 화면 크기에서 웹사이트가 어떻게 보이는지 확인해보세요.

×
현재 크기: 375 x 667

* 보안 정책(X-Frame-Options)이 적용된 사이트는 표시되지 않을 수 있습니다.

사용 가이드
expand_more
웹 개발자나 디자이너를 위해 제작된 도구로, 별도의 기기 없이 브라우저 내에서 반응형 화면을 즉시 테스트할 수 있습니다.

iPhone, iPad 등 자주 쓰이는 해상도를 프리셋으로 제공하며, 자유로운 수치 입력을 통해 커스텀 환경을 구축할 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 상단 입력창에 테스트할 웹사이트의 URL을 입력하고 '불러오기'를 누릅니다.
  2. 제공된 기기 프리셋 버튼을 클릭하여 화면 크기를 즉시 변경합니다.
  3. 너비와 높이 수치를 직접 입력하거나 '회전' 버튼을 눌러 가로/세로 비율을 바꿀 수 있습니다.
  4. 실제로 스크롤하거나 링크를 클릭하며 반응형 레이아웃을 검토하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
화면이 하얗게 나오거나 불러와지지 않아요.
Google, Naver 등 일부 대형 사이트는 보안상의 이유(X-Frame-Options: SAMEORIGIN)로 iframe 내 표시를 차단합니다. 이는 브라우저 보안 규정 때문입니다.
실제 모바일 기기와 100% 동일한가요?
해상도 환경은 동일하게 시뮬레이션하지만, 모바일 특유의 브라우저 엔진(Safari iOS 등) 특성이나 터치 센서 등은 PC 브라우저 환경을 따릅니다.

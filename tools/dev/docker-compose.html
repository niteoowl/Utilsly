Docker Compose 생성기는 여러 개의 도커 컨테이너를 한꺼번에 정의하고 실행하기 위한 YAML 설정 파일을 시각적으로 작성해주는 도구입니다. 데이터베이스, 백엔드 서버, 프론트엔드 등 유기적으로 연결된 서비스들의 포트 포워딩, 환경 변수, 볼륨 설정을 한눈에 파악하며 구성할 수 있습니다.

YAML 특유의 띄어쓰기(들여쓰기) 오류 걱정 없이 직관적인 인터페이스로 완벽한 설정 파일을 만들어보세요.
광고 영역 (상단)
check_circle 사용 방법
  1. 서비스 추가: '새 서비스 추가' 버튼을 눌러 컨테이너 단위를 생성합니다.
  2. 이미지 지정: 사용할 도커 이미지의 이름과 태그를 입력합니다 (예: nginx:latest, mysql:8).
  3. 네트워크/포트 설정: 호스트 포트와 컨테이너 내부 포트를 연결하고, 필요한 환경 변수를 키=값 형태로 입력합니다.
  4. 미리보기 및 다운로드: 오른쪽 창에서 생성된 YAML 코드를 확인하고 복사하여 프로젝트 루트에 저장하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
파일 이름은 무엇으로 해야 하나요?
일반적으로 'docker-compose.yml' 또는 'docker-compose.yaml'로 명명하며, 커맨드라인에서 바로 실행할 수 있습니다.
환경 변수(Environment)는 왜 필요한가요?
데이터베이스 비밀번호, API 키 등 실행 시점에 필요한 동적 설정을 컨테이너 내부로 전달하기 위해 사용합니다.
Restart Policy는 무엇을 선택해야 하나요?
서버 운영 환경에서는 컨테이너가 예기치 않게 종료되었을 때 자동으로 다시 시작하도록 'always'나 'unless-stopped'를 주로 사용합니다.

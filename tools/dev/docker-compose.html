Docker Compose 생성기

GUI 환경에서 서비스 정보를 입력하여 docker-compose.yml 파일을 완성하세요.

서비스 추가

YAML 프리뷰

version: '3.8' services:
사용 가이드
expand_more
복잡한 Docker Compose YAML 파일을 수동으로 편집할 필요 없이, 시각적인 폼을 통해 빠르게 생성할 수 있습니다. 서비스명, 사용할 이미지, 포트 포워딩 설정을 입력하면 즉시 유효한 YAML 코드가 생성됩니다.
광고 영역 (상단)
check_circle 사용 방법
  1. '서비스 이름'과 사용할 '이미지'를 입력합니다.
  2. 포트 연결이 필요한 경우 호스트와 컨테이너 포트를 각각 입력합니다.
  3. '서비스 추가'를 누르면 우측에 실시간으로 YAML 코드가 업데이트됩니다.
  4. 완성된 코드를 '복사' 버튼으로 가져가 파일로 저장하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
환경 변수나 볼륨 설정은 어떻게 하나요?
현재 버전은 기본적인 이미지 및 포트 설정을 지원하며, 고급 설정은 추후 업데이트될 예정입니다.
YAML 형식이 올바른가요?
네, 표준 Docker Compose 3.8 포맷에 맞춰 생성됩니다.

check_circle 사용 방법
  1. 페이지에 접속하면 자동으로 IP 주소 조회가 시작됩니다.

  4. VPN을 켜거나 네트워크를 변경했을 경우 '새로고침'을 눌러 다시 확인하세요.

help 자주 묻는 질문 (FAQ)
공인 IP와 사설 IP는 무엇이 다른가요?
공인 IP는 외부(인터넷)에서 나를 찾을 수 있는 유일한 주소이고, 사설 IP(예: 192.x.x.x)는 공유기 내부에서 우리 가족이나 사무실 기기끼리 구분하기 위한 주소입니다.
위치 정보가 정확한가요?
IP 기반 위치 정보는 통신사의 서버 위치를 나타내므로 실시간 GPS 위치와는 차이가 있을 수 있습니다. 보통 시/도 단위까지만 일치합니다.

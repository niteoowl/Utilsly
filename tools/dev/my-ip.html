내 IP 주소 확인 도구는 현재 내가 인터넷에 연결되어 있는 외부(공인) IP 주소를 즉시 알려줍니다.

복잡한 설정 확인 없이 접속하는 것만으로 IP 주소와 함께 접속 국가, 통신사 정보 등을 한눈에 파악할 수 있으며, 개발이나 네트워크 설정 확인 시 유용하게 사용할 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 페이지에 접속하면 자동으로 IP 주소를 불러옵니다.
  2. 가운데 큰 글씨로 표시된 IP 주소를 클릭하여 클립보드에 복사할 수 있습니다.
  3. 하단의 정보 카드에서 접속 위치와 통신사 정보를 확인합니다.
  4. 정보가 갱신되지 않는다면 '새로고침' 버튼을 클릭하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
공인 IP와 사설 IP의 차이가 무엇인가요?
공인 IP는 인터넷 세상에서 유일한 주소이고, 사설 IP(공유기 IP)는 집이나 사무실 내부망에서만 사용되는 주소입니다. 이 도구는 '공인 IP'를 보여줍니다.
VPN을 사용하면 어떻게 되나요?
VPN을 켜면 실제 내 주소가 아닌 VPN 서버의 IP 주소와 서버가 위치한 국가 정보가 표시됩니다.

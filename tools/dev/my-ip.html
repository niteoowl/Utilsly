내 IP 주소 확인 도구는 현재 인터넷에 연결되어 상대방 서버에 노출되는 공인 IP(Public IP)를 즉시 확인할 수 있는 도구입니다. 이 정보와 함께 네트워크 서비스 제공업체(ISP)와 접속 중인 국가, 도시 정보를 함께 제공합니다.

개인정보 보호를 위해 상세한 주소까지는 추적하지 않으며, 공개적으로 제공되는 IP 지리 정보를 기반으로 데이터를 표시합니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 자동 로딩: 페이지에 접속하면 별도의 조작 없이 자동으로 사용자의 공인 IP를 조회합니다.
  2. 상세 정보 확인: ISP, 국가, 도시 정보를 통해 현재 네트워크 상태를 확인하세요.
  3. IP 복사: 메인 카드의 'IP 주소 복사' 버튼을 눌러 편리하게 IP를 저장할 수 있습니다.
  4. 새로고침: 네트워크 환경이 바뀌었다면 '정보 다시 불러오기' 버튼을 클릭하세요.

help 자주 묻는 질문 (FAQ)
공인 IP와 사설 IP의 차이가 무엇인가요?
공인 IP는 인터넷상에서 유일한 주소이며 외부 기기가 나를 찾을 수 있는 주소입니다. 사설 IP는 공유기 내부에서 할당하는 주소(예: 192.168.x.x)로 외부에서는 보이지 않습니다. 본 도구는 공인 IP를 보여줍니다.
표시되는 위치가 실제와 조금 다릅니다.
IP 기반 위치 정보는 ISP의 장비 위치를 기준으로 하므로, 실제 거주지 주소와는 차이가 발생할 수 있습니다. 이는 지극히 정상적인 현상입니다.
VPN을 사용하면 어떻게 나오나요?
VPN을 사용 중이라면 실제 나의 IP 대신 VPN 서버의 IP와 해당 서버가 위치한 국가 정보가 표시됩니다.

사용 가이드
expand_more
진수 변환기는 한 숫자를 다른 진법 체계로 즉시 변환해주는 도구입니다. 컴퓨터 과학에서 필수적인 2진수, 16진수뿐만 아니라 2진수부터 36진수까지의 사용자 정의 변환을 모두 지원합니다.

실시간 변환 기능을 탑재하여 값을 입력하는 즉시 모든 칸의 숫자가 함께 동기화됩니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 변환하고 싶은 숫자를 해당되는 진법 칸에 입력합니다 (예: 10진수 칸에 255 입력).
  2. 입력과 동시에 다른 모든 칸(2진수, 16진수 등)에 변환된 결과가 출력됩니다.
  3. 사용자 정의 진수 칸에서는 원하는 진법(2~36)을 직접 설정하여 계산할 수 있습니다.
  4. 복사 아이콘을 누르면 해당 진법의 변환 결과를 클립보드에 바로 저장할 수 있습니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
16진수 입력 시 소문자도 사용 가능한가요?
네, a~f 소문자와 A~F 대문자 모두 지원하며 자동으로 인식하여 변환합니다.
사용자 정의 진수는 몇 진수까지 지원하나요?
숫자(0-9)와 알파벳(A-Z)을 사용하는 최대 36진수까지 변환이 가능합니다.

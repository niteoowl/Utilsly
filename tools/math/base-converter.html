진수 변환기

입력하는 즉시 2진수, 8진수, 10진수, 16진수로 상호 변환합니다.

10진수
올바른 10진수를 입력하세요.
2진수
올바른 2진수를 입력하세요(0, 1만 허용).
8진수
올바른 8진수를 입력하세요(0-7 허용).
16진수
올바른 16진수를 입력하세요.
광고 영역 (중간)
사용 가이드
expand_more
진수 변환기는 프로그래밍이나 데이터 분석 시 자주 사용되는 진수 간의 상호 변환을 지원하는 도구입니다. 10진수뿐만 아니라 컴퓨터 통신의 기초인 2진수, 하드웨어 주소 표현에 쓰이는 16진수 등을 한자리에서 확인할 수 있습니다.

복잡한 계산 과정 없이 숫자만 입력하면 즉시 다른 모든 진수로 자동 계산되어 표시됩니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 값 입력: 변환하고 싶은 숫자를 해당하는 진수 칸에 입력하세요.
  2. 실시간 확인: 입력과 동시에 다른 모든 입력창의 숫자가 자동으로 업데이트됩니다.
  3. 복사하기: 결과값 우측의 아이콘을 클릭하여 클립보드에 바로 복사할 수 있습니다.
  4. 초기화: '초기화' 버튼을 눌러 모든 입력값을 쉽게 비울 수 있습니다.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
입력할 수 있는 숫자의 크기 제한이 있나요?
자바스크립트의 안전한 정수 범위(Number.MAX_SAFE_INTEGER) 내에서 정확하게 변환됩니다. 아주 큰 숫자의 경우 오차가 발생할 수 있으니 주의하세요.
음수 변환도 가능한가요?
현재 버전은 양의 정수 변환을 우선적으로 지원하며, 음수(보수 표현) 기능은 추후 업데이트 예정입니다.
대문자/소문자 16진수 구분이 있나요?
16진수 입력 시 소문자와 대문자 모두 인식하며, 결과는 표준화된 대문자로 표시됩니다.

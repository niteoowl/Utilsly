진수 변환기
numbers

진수 변환기

2진수, 8진수, 10진수, 16진수 숫자를 입력하면 다른 진법으로 즉시 변환됩니다.

Decimal (10진수) Base 10
유효한 10진수 숫자가 아닙니다.
Binary (2진수) Base 2
유효한 2진수 숫자가 아닙니다.
Hexadecimal (16진수) Base 16
유효한 16진수 숫자가 아닙니다.
Octal (8진수) Base 8
유효한 8진수 숫자가 아닙니다.
사용 가이드
expand_more
수학 계산이나 프로그래밍에서 자주 쓰이는 진법 변환을 도와주는 도구입니다.

어느 한 곳에 숫자를 입력하면 나머지 3개의 진법으로 자동으로 변환되어 표시되므로, 번거로운 수동 계산 없이 결과를 즉시 얻을 수 있습니다.
광고 영역 (상단)
check_circle 사용 방법
  1. 변환하려는 진법의 입력창(예: 10진수)을 클릭합니다.
  2. 숫자를 입력하면 입력되는 즉시 다른 입력창들의 값이 자동으로 갱신됩니다.
  3. 16진수는 A~F 문자를 포함할 수 있습니다.
  4. 결과값을 클릭하여 복사한 뒤 필요한 곳에 사용하세요.
광고 영역 (하단)
help 자주 묻는 질문 (FAQ)
변환 가능한 숫자의 범위가 있나요?
자바스크립트의 정수 처리 한계 내에서 매우 큰 숫자까지 지원합니다. 소수점이 포함된 숫자는 현재 지원하지 않습니다.
16진수 입력 시 대소문자를 구분하나요?
아니요, 대문자와 소문자 모두 유효하게 인식하며 결과는 가독성을 위해 대문자로 표시됩니다.

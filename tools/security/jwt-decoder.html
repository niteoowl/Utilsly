JWT 디코더

JSON Web Token을 로컬에서 즉시 디코딩하여 페이로드를 확인합니다. 데이터는 서버로 전송되지 않습니다.

HEADER: 가장 먼저 알고리즘과 토큰 타입을 정의합니다 PART 1
PAYLOAD: 데이터 본문 (Claims) PART 2
SIGNATURE: 변조 여부 확인을 위한 서명 데이터 PART 3
사용 방법
expand_more
  1. 입력: 'eyJ...'로 시작하는 JWT 토큰 값을 입력창에 붙여넣으세요.
  2. 확인: 자동으로 Header와 Payload 부분이 디코딩되어 표시됩니다. 만료 시간(exp) 등 주요 정보도 보기 쉽게 제공됩니다.
  3. 분석: 토큰에 담긴 사용자 정보나 권한 등을 확인하세요. (서명 검증은 하지 않음)
